# 开头（第 2 步）和标题

开头只有三种。AI 每种出 1–3 条候选，标一个推荐，**Park 点一个**。不管哪种，每条后面都标它靠原文哪一句撑着；原文撑不住的不写。

## 三种开头

| 开头 | 例子 | 原文里有什么时推荐 |
|---|---|---|
| **数字** | 「我停更半年，只有 6000 粉丝，三天接了三单 2000 块的咨询。」「AI 已经从 50 分变成 80 分，80 分的人写的 skill 只有 70 分。」 | 原文有带单位的数字（十倍、99 件、1%、6000 粉、两万亿） |
| **反常识暴论** | 「讲出来一定会被很多人骂……20 万粉以下，没有任何必要精雕细琢任何一条短视频。」 | 原文在否定一个大家默认对的东西 |
| **直接说** | 「所有做自媒体的人，这篇你一定要给我看完。」 | 讲方法、讲流程，读者是一类明确的人 |

### 数字

- 第一句里带一个**带单位的数字**。他自己的 5 条爆款里 3 条有，6 条没爆的 0 条有；对标爆款 58% 有，没爆 39%。（10/9，173 份拆解）
- **推荐用带数字的判断**（「80 分的人写的 skill 只有 70 分」）。10/9 测过：不写死这条，AI 会把「我把 skill 从 600 砍到 200」这种成绩放第一句。
- 结果数字（「三天三单 2000 块」，10/2 付息稿样例的开头）可以作为一条候选给 Park 挑，第二句马上接判断；不作为推荐。
- 数字只能是原文里的。

### 反常识暴论

来自一勾 24 条视频的开头，按点赞倍数排：

| 句式 | 原话 | 倍数 |
|---|---|---|
| 预告会挨骂 + 绝对判断 | 「讲出来一定会被很多人骂……20 万粉以下，**没有任何必要**精雕细琢任何一条短视频」 | **6.2×** |
| 身份反差 | 「我今年 26 岁，但我后端客户**全部都是** 28–40 岁的高净值女性」 | 1.9× |
| 绝对否定 | 「到现在还不会做深度内容的人，你**不可能**获得高端客户」 | 1.5× |
| 攻击一个流行说法 | 「我觉得这行**最大的骗局**就是『你要去赚有钱人的零花钱』」 | 1.1× |
| 绝对否定（但没数字） | 「我觉得**压根就不存在**第一条视频就能变现这样的说法」 | **0.3×** |

- **用绝对词**：一定、全部、不可能、压根不存在、没有任何必要、最大的骗局。含糊的判断不是暴论。
- **否定一个大家默认是好的东西**（精雕细琢、赚有钱人的钱、粉丝多）。
- **离钱近**；**一口气说完**，不依赖标题也成立。
- **不许硬拗。** 一勾自己有一条视频专门骂「硬拗一个反常识的观点来博眼球」，那条只有 0.9×。为了冲突把结论写得比证据更绝对，不行。

### 直接说

- 第一句直接点名这篇是给谁的，并要求他看完：「所有做自媒体的人，这篇你一定要给我看完。」
- 这句通常是**新写的**，所以只作为候选，Park 挑了才用（10/11 Park 定了这种开头；「新写一句」这个例外待他确认）：只写一句；点的人群必须是原文讲的那群人；文章里说「这篇」，口播里说「这条视频」。
- 数据上它没有优势：173 份拆解里，开头点名一类人，爆款和没爆的一样多。用它是因为对象清楚、承诺直接，不是因为它更容易爆。

## 不管哪种

- **不铺垫。** 「今天讲……」「现在是 X 月 X 号」「我做这件事是想……」不能当开头。
- **开头后面紧跟「凭什么信你」**：原文里他做过的事、成绩、数字，前 15 秒（约 60 字）内。
- **X 长文**：summary 段固定在标题下面（Park 10/9 要的「第一段」），开头句是正文的第一句。summary 已经说清楚这是什么，QA 就不再加导语。

## 输出

```markdown
## 开头候选（推荐：<哪一种>，因为原文里有……）
1. 数字：「……」（依据：「原文那一句」）
2. 暴论：「……」（句式 · 依据：「……」）
3. 直接说：「……」（人群依据：「……」；这一句是新写的）
```

## 标题

刷到的人先看见标题，再读第一句。所以标题和开头是一个标准：**暴论或数字，而且原文撑得住。** 出 6–10 个候选，Park 自己挑，不替他定。

| 句式 | 例子 | 什么时候用 |
|---|---|---|
| 绝对否定 | 「20 万粉以下，没有任何必要精雕细琢短视频」 | 原文里有一个斩钉截铁的判断 |
| 攻击流行说法 | 「这行最大的骗局，就是赚有钱人的零花钱」 | 原文在反驳一个大家默认对的说法 |
| 悖论 | 「越想赚钱，越要先送产品」 | 原文里有「越 A 越 B」的反直觉因果 |
| 借力点名 | 「我终于理解了 dontbesilent 为什么开源 dbskill！」 | **原文里点名提到了一个具体的人或产品** |
| 算账 | 「一条视频 3 个私信，靠什么活？」 | 原文里有真实的数字可以摆 |
| 身份反差 | 「26 岁，客户全是 28–40 岁的高净值女性」 | 原文里有 Park 自己的反差身份 |

- **借力点名是硬要求。** 原文点名提到的人（博主、公司、产品），至少出一条借力候选，把名字原样放进标题。9/23 那条视频 Park 最后用的就是点名 dontbesilent 的那条——点名的人自带搜索量和好奇心。
- 用绝对词；离钱近；一口气读完，不要冒号接副标题、不要两段式。
- **不超过 30 个字**（抖音标题栏上限）。
- **不许编数字**，标题里的每个数字都必须在原文里出现过；每条标依据。
- 不要「AI 时代，……」这种万能开头；不要问句套问句（「你知道……吗？」）；不要讲课口吻（「三个方法教你……」）；不要把个人判断写成已经证实的事实。

```markdown
## 点名的人
dontbesilent、dbskill
（原文里没点名任何人就写「无」）

## 标题候选
1. 标题｜句式｜依据：「原文里的那一句」
2. ……
（6–10 条）
```
